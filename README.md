# VettedAuthority

Legitimate marketplace for publishing guest posts and sponsored content on high-DR authority sites.

**Live prototype ready to share and monetize.**

## Features
- Browse vetted high-DR publishers (editorial + sponsored)
- Write and submit articles
- User accounts (demo localStorage)
- Payment flow simulation for sponsored placements
- Dashboard for tracking submissions
- Publisher earning opportunity
- White-hat, FTC/Google compliant design

## Deploy & Share
This is a static site. Deploy instantly:

1. **Vercel** (recommended): Connect this GitHub repo → import → deploy. Free tier works.
2. **Netlify**: Drag-and-drop the folder or connect repo.
3. **GitHub Pages**: Enable in repo settings.

Public URL example after deploy: `https://vetted-authority.vercel.app`

## Monetization Path
- Sponsored placements: charge advertisers $299–$5,000+
- Platform commission (e.g. 20–30%)
- Publisher side: earn by accepting vetted submissions
- Connect **Stripe** for real payments (Checkout Sessions)
- Add backend (Supabase / Firebase / Node) for real users, orders, and publisher portal
